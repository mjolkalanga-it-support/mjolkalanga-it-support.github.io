# Mjölkalånga IT & Support

Minimal GitHub Pages-webbplats.

## Repo-namn
Använd detta exakta repo-namn för en ren GitHub Pages-adress:

`mjolkalanga-it-support.github.io`

Då blir adressen:

`https://mjolkalanga-it-support.github.io/`

## Filer
- `index.html` – startsida
- `robots.txt` – robotinstruktioner
- `sitemap.xml` – sitemap
- `prices.json` – maskinläsbar prisfil

## GitHub Pages
1. Skapa repot `mjolkalanga-it-support.github.io`
2. Ladda upp alla filer i repo-roten
3. Gå till Settings -> Pages
4. Välj Deploy from branch
5. Välj branch `main` och folder `/root`

## Domän senare
När du har egen domän kan du lägga till en `CNAME`-fil och peka DNS till GitHub Pages.
